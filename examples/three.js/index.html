RuView · three.js 演示

五个复杂度递进的浏览器演示，围绕 ADR-097 感知辅助场景展开，最终以真实 ESP32 CSI 数据驱动的 MediaPipe-Pose → Mixamo X Bot 实时重定向流水线收尾。

01 · Helpers 独立运行

点云查看器中的纯 ADR-097 辅助工具，无需外部资源。

02 · Cinematic 独立运行

在 #01 之上叠加电影感镜头与伪 CSI 可视化。

03 · Skinned (GLTF) 独立运行

ADR-097 场景中的 GLTF 蒙皮网格与叠加式动画混合。

04 · Skinned FBX 需要 FBX

通过 FBXLoader 加载 Mixamo X Bot，需要本地 assets/X Bot.fbx.

05 · Realtime (Pose + CSI) 需要 FBX

摄像头 → MediaPipe Pose Heavy → Mixamo IK 重定向，叠加实时 ESP32 CSI。
演示 04 与 05 需要 Mixamo 资源。Mixamo 的 X Bot.fbx 文件按授权约定不随本部署重新分发， 需由终端用户自行前往 mixamo.com 下载。 本地运行步骤：克隆仓库，下载 X Bot.fbx （FBX Binary、T-Pose、Without Skin）放入 examples/three.js/assets/，然后执行 python examples/three.js/server/serve-demo.py。
